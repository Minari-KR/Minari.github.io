# 일지 작성 가이드

새 일지를 작성할 때는 `TEMPLATE.md`를 복사한 뒤, 아래 순서로 원고만 작성한다. HTML 태그, 글자 크기, 줄간격은 직접 작성하지 않는다.

## 원고 형식

1. 제목은 핵심 경험이 드러나도록 짧게 쓴다.
   - 예: `대전 인디 게임잼 참여 후기`
2. 날짜는 `YYYY-MM-DD` 형식으로 쓴다.
3. 소제목은 3~6개로 나눈다.
   - `##`로 시작한다.
   - 한 소제목에는 하나의 이야기만 담는다.
4. 한 문단은 2~4문장을 권장한다.
   - 문단을 바꿀 때는 빈 줄을 하나 둔다.
5. 문체는 자연스럽게 섞는다.
   - 모든 문장을 `-다.`로 끝내지 말고 짧은 문장, 질문, 설명형 문장을 함께 사용한다.
6. 사진·링크·강조가 필요하면 원고에 함께 적는다.

## 작성 후 Codex에 요청하는 문장

아래처럼 원고를 붙여 넣고 요청한다.

> `journal/TEMPLATE.md` 형식의 원고를 새 일지로 만들어줘. 기존 일지 디자인과 모바일 규칙, 홈 목록·모바일 프리뷰에도 반영해줘.

Codex가 제목·날짜·소제목·문단 구조를 확인한 뒤, 공통 디자인을 적용한 HTML과 홈 목록 항목을 작성한다.

## 지켜지는 디자인 규칙

- 일지 상세: 제목, 날짜, 소제목, 본문, 목록으로 돌아가기 링크의 구조를 공통으로 사용
- 본문: 글자 크기·줄간격·문단 간격을 공통 CSS로 적용
- 모바일: 제목 한 줄 규칙과 카드 여백을 공통으로 적용
- 홈 목록: 동일한 카드 크기와 제목 단계로 표시
